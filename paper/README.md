## Not compiled

There is no TeX installation on the machine this was drafted on, so `apg.tex`
has **never been run through LaTeX**. It passes a structural check only:
environments balanced, braces balanced, every `\ref` resolving to a `\label`,
every `\cite` to a `\bibitem`, and no redefinition of a built-in command. That
check caught one real error --- a `\newcommand` for `\deg`, which is already
defined --- but it is not a build, and the first real compilation should be
expected to turn up formatting problems.

```
pdflatex apg.tex && pdflatex apg.tex
```
